# 市场均衡价格模拟器

> Market Equilibrium Simulator — 二分法求解 · 随机冲击模拟

基于微观经济学供需模型，使用**二分法**高精度求解市场均衡价格，支持**乘法型随机冲击**引擎，可分别对需求端和供给端施加外生扰动，逐轮追踪价格与供需量的动态变化，直观展示外生冲击在市场中的传导路径。

---

## 模型

程序使用线性供需函数：

```
需求:  Qd = a − b·P      (b > 0, 向下倾斜)
供给:  Qs = c + d·P      (d > 0, 向上倾斜)
```

令超额需求函数 `E(P) = Qd − Qs = (a − c) − (b + d)·P`。当 `b + d > 0` 时，`E(P)` 严格单调递减，在区间内存在唯一零点——即均衡价格 `P*`。

**代数精确解：** `P* = (a − c) / (b + d)`

---

## 算法

### 二分法搜索

替代传统线性扫描（`for P = 0; P ≤ 1e6; P += n`），使用二分法在 `[0, 1e6]` 区间内搜索：

| 指标 | 线性扫描 | 二分法 |
|------|----------|--------|
| 时间复杂度 | O(1e6 / n) | O(log(1e6 / tol)) |
| 精度 | 取决于步长 n | `1e-8`（固定） |
| 最大迭代 | 最多 ~1,000,000 步 | ≤ 200 步 |
| 验证方式 | 无 | 与代数精确解对比，计算绝对误差 |

### 随机冲击引擎

每轮冲击为乘法型扰动：

```
a' = a × (1 + δ)    δ ∈ [−range, +range] 均匀分布
c' = c × (1 + δ)
```

冲击逐轮**累积**——上一轮冲击后的参数作为下一轮的基准，模拟市场在持续扰动下的演化路径。

---

## 功能

- **二分法求解** — 高精度（1e-8）、带精确解对照
- **三种冲击模式** — 仅需求 / 仅供给 / 供需双重
- **逐轮表格输出** — 7 列完整追踪：轮次、需求冲击%、供给冲击%、新均衡 P*、价格变动%、新 Qd、新 Qs
- **汇总对比** — 冲击前后初始 vs 最终均衡价格，累计变动幅度
- **参数校验** — 自动检测 `b + d ≤ 0` 等无解情形

## 输出解读

| 列 | 含义 |
|----|------|
| **轮次** | 第 k 轮冲击 |
| **需求冲击%** | 需求截距 a 的本轮变动百分比 |
| **供给冲击%** | 供给截距 c 的本轮变动百分比 |
| **新均衡 P\*** | 冲击后二分法求得的新均衡价格 |
| **价格变动%** | 相对上一轮均衡价格的变动 |
| **新 Qd / 新 Qs** | 新均衡下的需求量和供给量（应相等） |

- 需求正冲击（+%）→ 需求曲线右移 → 均衡价格**上升**
- 供给正冲击（+%）→ 供给曲线右移 → 均衡价格**下降**
- `[无解]` 出现在极端冲击导致供需曲线不再相交时

---

## 冲击模式对比

| 模式 | 扰动对象 | 经济学含义 |
|------|----------|------------|
| 1 — 仅需求 | 需求截距 a | 消费者偏好、收入水平变化 |
| 2 — 仅供给 | 供给截距 c | 生产成本、技术条件变化 |
| 3 — 双重冲击 | a 和 c 同时 | 市场全面受到外部扰动 |
